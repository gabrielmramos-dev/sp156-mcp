# Política de segurança

Este é um projeto individual, mantido em regime de melhor esforço.

## Versões suportadas

Apenas a branch `main`. Ainda não há versões publicadas.

## Como reportar uma vulnerabilidade

**Não abra uma issue pública.** Use o relato privado do GitHub:
<https://github.com/gabrielmramos-dev/sp156-mcp/security/advisories/new\>

## O que está no escopo

- Falhas no código (execução de código, leitura de arquivos fora do esperado, injeção em consultas SQL).
- **Exposição de dados pessoais.** O projeto promete não ler nem expor endereço, número, CEP e coordenadas. Se encontrar um caminho em que isso aconteça, é uma falha de segurança.
- Dependências com vulnerabilidades conhecidas que afetem o projeto.

## Fora do escopo

Problemas nos próprios dados da Prefeitura de São Paulo. Eles devem ser reportados à fonte.
